# SK네트웍스 Family AI캠프 - 데이터 수집 요약

## 1. 오픈 API를 이용한 데이터 수집
* **API 개념**: 서로 다른 컴퓨터 프로그램끼리 통신할 수 있도록 돕는 규약 (REST API, 라이브러리 API 등)
* **JSON 데이터 표준**:
  * 키-값(Key-Value) 쌍으로 구성된 텍스트 기반 데이터 포맷
  * Python `dict`와 유사하나 문자열(`string`) 구조이며 반드시 큰따옴표(`"`) 사용
  * Python 변환: `json.loads(json_string)` 활용
* **실습 (도서관 정보나루 API)**:
  * 인증키(`authKey`) 발급 후 호출 URL 구성 (`http://data4library.kr/api/loanItemSrch?...`)
  * Python `requests.get(url).text`를 통해 데이터를 수령하고 JSON 파싱 후 CSV 저장

## 2. MySQL DB 저장 및 데이터 검증 (SQL)
* **DB 및 테이블 설계**:
  * `testdb` 생성 (`utf8mb4` 인코딩 설정)
  * `book_table` DDL 정의 (순번, 대출순위, 도서명, 저자, 출판사, 대출건수 등)
* **데이터 적재 및 조회**:
  * MySQL Workbench의 **Table Data Import Wizard**로 CSV 데이터를 DB 테이블에 매핑하여 적재
  * `SELECT COUNT(*)`로 총 200건 적재 완료 검증
  * `WHERE loan_count >= 8000`, `WHERE author_name LIKE '%한강%'` 등 조건별 필터링 실습

## 3. 웹 크롤링(Web Crawling)과 HTML/CSS 기초
* **크롤링 구분**:
  * **정적 크롤링**: 고정된 데이터를 빠르게 수집 (`Requests`, `BeautifulSoup`)
  * **동적 크롤링**: 상호작용(스크롤, 클릭 등)이 필요한 실시간 데이터를 브라우저를 구동하여 수집 (`Selenium`)
* **HTML/CSS 핵심**:
  * 기본 구조: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`
  * 주요 태그: `<a>`, `<h1>~<h6>`, `<ul>/<ol>/<li>`, `<table>`, `<div>`
  * `id`(고유 식별자) 및 `class`(그룹 식별자)를 활용한 요소 선택

## 4. Selenium을 이용한 동적 크롤링 실습
* **요소 탐색**: 개발자 도구(F12)의 '요소 선택 아이콘' 및 `Copy selector` 기능 활용
* **Selenium 핵심 3단계**:
  1. 브라우저 생성: `driver = webdriver.Chrome()`
  2. 페이지 이동: `driver.get(url)`
  3. 데이터 추출: `driver.find_element(By.CSS_SELECTOR, selector).text`
* **생성형 AI 활용**: HTML 구조 정보 및 프롬프트를 AI에 제공하여 복잡한 웹 페이지 수집 코드 자동화
